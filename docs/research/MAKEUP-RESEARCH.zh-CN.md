# 妆容、表情、表观年龄：研究与实现约束

检索日：2026-09-30。附件 JSON 为候选目录；没有运行任何生成模型实验，所有生成效果、身份保持和漂移风险均未经实测。品牌材料用于说明技法和命名，不采信“万能显年轻”“黄金比例”等营销结论。

## 先分层，而不是把风格词堆进脸型

1. 结构层：五官形态、位置及用户已有身份字段。妆容预设不写入这里。
2. 彩妆层：表面色彩、遮盖度、反射特性、绘制边界、毛发梳理和附加装饰。改变轮廓的视觉阅读，并不等于移动骨骼。
3. 表情层：眉位、眼睑开合、凝视方向、嘴唇开合、嘴角与面颊运动。它本来就会改变可见几何，因此不能承诺与静态结构完全无交互。
4. 年龄层：明确选择的表观年龄目标。与肤质/软组织外观相关，默认关闭或继承已有值；新人物使用成年人兜底。不得被“清透”“成熟”“少女感”等妆型偷偷改写。

保证“不改存储的结构字段”是软件行为；“生成图不换人”是尚未证明的模型行为。不要混写。

## 专业分类与字段

- 底妆：遮盖度 none/sheeer/medium/full，与 natural/matte/satin/dewy 妆面分开。全遮盖不等于白肤色；水光不等于年轻。Kryolan 的专业粉底分类支持区分这些维度。
- 眉：原形毛流补画、柔雾填充、清晰边界、上梳、遮眉重画。眉位与眉峰如要变动，标注是“画出的眉轮廓”，不改骨骼/眼眶字段。
- 眼线：睫毛根部细线、短上扬尾、横向延长、晕染、几何悬浮线、上下包围描边。几何描述优先于“狐狸眼/猫系脸”等可能联动眼裂结构的标签。
- 睫毛：分明、中央加强、外侧加强、舞台夸张；眼影：单色铺色、外侧渐层、烟熏、眼窝图形、中央提亮。色盘、边缘软硬、反光材质还可继续独立。
- 腮红：面颊中央、颧部高位、颧外侧至太阳穴 C 形、鼻梁连贯横向。NARS 明确区分位置和 matte/satin/shimmer 妆效；不建立“圆脸只能怎样”的规范。
- 修容/高光：阴影位置、边缘软硬、强度和反射分开。画鼻侧阴影不写成鼻梁变窄；颧下阴影不写成瘦脸。
- 唇：自然边界、柔焦边界、内深外浅、深边浅心、越界描画、缩小绘制；另分染色、缎光、哑光、光泽、金属。MAC 的深边浅心示例直接沿原唇线，不必自动丰唇。
- 装饰：贴钻、绘制雀斑、额心纹样属于附加表面图案；真实雀斑/痣与画出的图案须分字段，避免遮盖身份线索。

## 优先实现的 21 个候选

JSON 中含不加彩妆、轻透原肤、缎光中遮盖、哑光全遮盖、3 个眉妆、3 个眼妆、2 个腮红、浅修容、3 个唇妆、2 个有日期社媒配方和 3 个历史启发式组合。它们是由来源支持的技法组合，不声称原文给出完全同一配方。

“自然”“经典”“轻透”是视觉描述；不要用“高级/低级”“清纯/不检点”“天生贵气”等社会评价作为效果字段。

## 历史文化：把确定性写进数据

- 1960 年代 Mary Quant/London：V&A 说明较克制的脸/唇与眼部重点，以及可互换协调的彩妆体系。可做眼部重点启发预设；不能自动白化人物，也不能把一项广告形象等同整个英国女性群体。精确复原需指定广告/年份/照片。
- 1920 年代美国都市/银幕启发：Smithsonian 记录可见睫毛膏、眼线、暗色眼影和唇膏的推广。可以组合；细眉、特定丘比特唇形需要具体人物/参考，不凭“20年代”自动加入。
- 古埃及：British Museum 资料确证男女使用黑色 kohl 描眼、加深睫毛。未据此确认任何通用“克娄巴特拉金蓝眼影”配方；这类名称只能作启发式，不改族裔或肤色。
- 歌舞伎隈取：日本艺术文化振兴会的原始表演资料说明角色相关的颜色、线条和晕染。这是角色戏妆，不是“日本女性妆”。涉及颜色与角色性格的历史符号应仅保留在戏剧语境，不能套用真人道德判断。现放扩展候选，要求具体角色。
- 中国花钿/面靥：本轮未获取足够具体的官方图像/文物上下文来制定整套历史妆容，保留待核验。特别注意故宫《唐妆》词条讲的是仕女画样式，不能误当唐代化妆步骤的史料。下次应查敦煌指定窟号/壁面/年代、墓葬俑或研究论文，区分额心面饰和同名头饰。
- 地域婚礼妆、艺伎/舞妓、中国戏曲旦角等：需具体地域、年代、角色或仪式材料，不能用民族名称代替配方。

## 当代标签：按有日期的配方存档

Clean girl 可作为“轻透水光、上梳眉、少量腮红、原唇色光泽”的检索别名，依据 Maybelline UK 2025-10-16 的一种配方；名称不暗示卫生或人格。MAC Sunset Spritz 2025-05-27 可落实为橙粉渐层腮红与光泽唇。不要声称在 2026 年仍普遍主流；不要把任何网络流派当成固定国别妆容。Douyin、latte、cold girl、siren 等后续按创作者/平台/日期采样，拆回几何与材质字段。

## 表情与年龄

FACS 的用途是拆解可见面部运动，因此可借鉴“眉、眼睑、嘴角、嘴唇、面颊”分解法；本目录未做标准 AU 编码，不应声称通过了 FACS 验证。预设可提供自然静息、轻微闭唇笑、露齿笑、轻抬眉、双唇轻启、目光下移。若添加皱眉/惊讶，应描述眉向内下、上睑抬起、嘴唇轻启等视觉动作，不承诺反映真实心情或人格。

年龄研究尤其反对单方向规则：Russell 等（2018 在线发表，2019 期刊）在其女性照片实验中发现，化妆使中年组被判断更年轻，却使年轻成人组被判断更年长，30 岁组未出现同样差异。这是特定实验与观察者的知觉结果，不可推导为个体规律或图像模型能力。NIH 的年龄皮肤材料支持质感、弹性与饱满度可随年龄变化，但差异大，不支持每岁对应多少皱纹的函数。

整数年龄 UI 也可用，但导出 approximately、提示目标非精确保证，不映射皱纹数量。默认不加灰发、干瘦、悲伤或特定肤色；年龄变化不应顺带改变性别/族裔字段。

## 组合、覆盖、互斥

- 模块 off：不输出该层（是否抑制旧层由迁移规则明示）；inherit：不干预既有值；none：明确无该部位彩妆。这三个状态不可混为一个空字符串。
- 成套预设先解析，再应用用户逐项 override。最后每个单值槽只输出一条已解决描述；不要同时输出清透/全遮盖、无眼线/猫眼线、哑光唇/亮光唇。
- 全局色盘只是默认色；局部唇色可覆盖唇部而不强改腮红。脸部哑光与嘴唇亮光可以共存，应按区域判断冲突。
- 成套预设不得无意写年龄/表情/发型/肤色/族裔；成套化妆与发型通过不同模块任意组合。
- 历史或文化包可给“语境不一致”提示，不做族裔硬禁用。跨文化设计不等于真实性复原。
- 真正修改几何的重画眉、过度越界唇线、假眼褶、舞台变装/假体等应有显式选项与交互提示；不把它们混入低干预默认。

## 验证预期

软件单元测试：旧存档未启用时不变；预设选用只更改自身命名空间；unknown key 不进入 prompt；关闭与继承不混；局部覆盖胜于包默认；每槽单一解析值；无隐式年龄/肤色/族裔修改；表达层不会反写基础嘴型/眼型；年龄无无效数值、越界或自动幼态切换。

模型实验（待做）：固定参考脸、相机/光线/姿态与所有其他提示，只改变一个字段；同条件多次生成，避免把随机性当作用。跨肤色、已有脸型、成人年龄、性别表现采样。人工检查可识别为同一人、目标妆是否可见、未请求结构变化、肤色漂移、识别痣/雀斑是否被遮盖。加入高风险组合（重修容+高遮盖+重画眉、笑容+眼妆、年龄+肤质），单独比较“只写流行标签”和“明确部位描述”。相似度模型可作辅助，不能等同真实身份正确；不预设任何风险百分比或通过率。
