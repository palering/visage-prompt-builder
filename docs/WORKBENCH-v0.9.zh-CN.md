# Visage v0.9：离线头部与体型工作台

## 直接打开

双击 `dist/visage-workbench.html`，无需 Node、服务器、安装或联网。现代 Chrome / Edge / Firefox / Safari 可打开单文件 HTML。完整源代码也在本包中；开发者可运行 `npm test`，再运行 `npm run build:web` 重建同一个离线入口。

工作台只生成提示词和 JSON，不调用图像模型，不上传照片，不创建在线画廊。服装系统暂不包含；全身构图固定采用不透明的普通日常衣物作为中性展示描述。

## 使用顺序

1. 在头部区域启用需要的参数；未启用的参数不写入提示词。各分区可收起，保留面部骨架、软组织、眼睛、眉毛、鼻子和嘴唇独立控制。
2. 用可搜索的发型及妆容预设选项，或选择继承 / 关闭。继承使用已有 profile 的该层；关闭明确抑制已有该层；选择预设取代该层。年龄仅允许 18–90 岁，角色限定成年人。
3. 需要体型时启用体型模块，选择全身构图。再按需勾选单项并拖动滑块。全局关闭会保留编辑值，但不输出体型描述。
4. 头肩构图只输出头部，不输出已保存的体型描述；再次选择全身构图时可恢复。头肩 / 全身不会同时写入同一提示词。
5. 查看实时提示词。复制失败时可在文本框中手动全选复制。导出 JSON 保存完整配置；导入时检查版本、范围和字段，错误不会替换已有内容。
6. “保存本机”使用当前浏览器本地存储；不同浏览器、私密浏览、清除站点数据可能无法保留。重要配置请导出 JSON。离线文件浏览器若限制本地存储，使用导入 / 导出。
7. 随机按钮只重新采样头部，保持体型、外观和构图设置；相同 seed + 相同 catalog 可重现参数，不保证生成图片人物身份。重置恢复稀疏默认头部、体型关闭和头肩构图。

## 体型模型：17 项，三层分离

| 层 | 参数 |
| --- | --- |
| 骨架与比例 | 肩架、胸廓、骨盆宽度；腿长和臂长比例 |
| 局部肌肉体量 | 三角肌、胸肌、背阔肌轮廓、上臂、大腿、小腿、臀肌 |
| 外轮廓 / 软组织 | 腰线收束、腹部线条、乳房体量、腹部软组织、胯外侧软组织 |

0–100 是选择界面的艺术控制坐标，不是厘米、体重、BMI、体脂率、力量、健康或人体测量。采用三档文本：0–33 低档、34–66 中档、67–100 高档。同档不同数值会得到相同提示词，界面不会暗示数值能精确约束图像。50 仅在明确勾选后输出中档；未勾选不默认填充中等体型。

肩架宽度不是肩部肌量；胸廓、胸肌和乳房软组织分开；骨盆宽度、臀肌和胯外侧软组织分开。腹部线条与腹部软组织分别表达表面目标，可能互相制约；工具不声称参数之间在生理学上完全独立，也不保证图像模型严格遵从组合。

解剖资料支持的是部位与组织的区分，具体三档阈值及提示词是本项目编写的视觉目标，不是资料提供的人体标准。来源和限制见 [体型研究](research/BODY-RESEARCH.zh-CN.md)。

## 命令行

```bash
npm run build -- examples/appearance/base-profile.json --preset profile --body examples/body/moderate-adult.json --capture full_body
npm run build -- examples/appearance/base-profile.json --preset profile --appearance examples/appearance/hair-only.json --body examples/body/moderate-adult.json --capture full_body
```

`body-v0.1` 与 `face-v0.2`、`appearance-v0.1` 分开存储，不污染头部 schema。CLI 的 body 关闭或省略且不指定新 capture 时，保留旧版头部 prompt 字节级输出。选择 body 或明确 full_body 时，face profile 必须含 `subject.age_group: "adult"`。全身构图替换旧 profile 中的自由文本 capture，以防旧头肩镜头与全身构图冲突。

## 开发与兼容

浏览器入口直接打包原有 compiler、validator、appearance catalog 和 sampler 的同一份源码。构建阶段内联版本化 JSON，并为同步 SHA-256 与随机字节提供浏览器适配；没有远端依赖、eval、动态下载模块或第二套手写 prompt 规则。构建输出为静态单文件。

工作台配置版本为 `workbench-v0.1`。导入上限 1 MB，拒绝未知根字段、非法值、非成年主体、未知预设、非法采样方向以及原型污染字段。导出的配置用于再次编辑，并非不可变历史审计文件；随机头部仍保留原 sampler 的版本 / 哈希元数据，离线 HTML 与源代码版本应一起归档。已有样例及历史 manifest 未回写。

## 本次验证范围

120 项 Node 自动测试通过；20 个种子的 Node / 浏览器构建共享核心完整参数和 manifest 一致，独立审阅另验证 102 个种子一致。`npm run test:ui` 在最小 DOM 事件测试环境中验证源 UI 与离线构建的开关、滑块、搜索、随机、保存/读取、复制降级、JSON 导入/导出及延迟导入竞态。

实际 Chromium 被当前执行环境的 socket 限制阻止；云浏览器无法读取本地文件。未完成真实桌面/手机屏幕的渲染、截图、原生文件选择器、浏览器存储及剪贴板权限验证。响应式布局和这些原生行为尚需实际浏览器验收；DOM 事件测试不等同于浏览器端到端测试。
