# Visage 0.11 · 卡片主题工作台

## 本版状态

这是基于 v0.10 的真实界面实现，保留原采样、编译与约束引擎。新增浅色 / 深色卡片主题、角色与版本、本地静态参考和预览 / 提示词高度分隔条。**本次运行环境缺少官方浏览器预览服务，未完成真实浏览器视觉验收。** 自动化结果不等同于实际布局、原生文件选择器或拖拽体验验证；详见根目录 `design-qa.md`。

## 打开与构建

先运行 `npm run build:web`，再打开生成的 `dist/visage-workbench.html`。本无图片备份不附带静态示例图；图标、样式及逻辑包含在单个文件里，无需联网、账号、后端或图像 API。

源代码需 Node.js 18+，没有外部 npm 运行依赖：

```sh
npm run build:web
npm test
npm run test:ui
```

`web/index.html` 是构建入口，请使用生成的离线 HTML；不要直接通过浏览器打开源模块入口。

## 四个区域

1. 左侧窄导航：角色、工作区、参数定位、主题切换和说明；可折叠，折叠后从角色栏展开
2. 角色栏：新建、切换、重命名角色；每个角色有独立草稿与版本快照
3. 中间：上方静态参考，下方实时英文提示词；拖动分隔条改变高度
4. 右侧：头部、外观、身体标签；人物设定、随机边界与构图设置均保留

界面保留所选参考的圆角叠层卡片，仅适度缩紧内边距、行和按钮。图标来自 Feather 4.29.2，MIT 许可，完整许可随源码和离线文件附带。

## 角色、版本与保存

- 初始是一个未保存角色，没有伪造的版本或其它角色
- 切换角色保留各自当前草稿，不会把另一角色的参数套进来
- “保存版本”创建不可变快照；点击旧版本会恢复到当前草稿，既有版本不变。请先保存要保留的未保存草稿
- 最多 30 个角色，每个角色最多 30 个版本
- “保存到本机”持久保存整个工作区；“读取”恢复最近一次本机保存。刷新或关闭前请保存
- 本机存储依赖当前浏览器与当前文件的存储隔离方式；换浏览器、移动离线文件或隐私模式时不保证能读取旧存储
- “导出当前 JSON”只导出当前角色的参数，兼容既有工作台格式；不会导出其它角色、版本历史、图片或界面偏好。重要版本请分别导出备份
- 保留 v0.10 单配置本机存储兼容：如果没有新版工作区，会读取旧配置并建立一个角色
- JSON 导入仍支持旧版工作台迁移。无效、过大或工作区不能安全保存的输入会在修改当前状态前拒绝

## 静态参考与提示词

完整原版的初始示例是项目已有的 v0.8 合成人物检查图。本无图片备份移除了该 PNG 和内嵌图片数据，初始预览为空，等待导入本地参考。参数改变只更新提示词，不生成图片。

可导入 PNG、JPEG、WebP、GIF，单张上限 10 MB。图片只在当前页面会话中显示，不上传、不写入本机工作区、不出现在 JSON 中。导入后修改参数，会出现“参数已更改”提示。移除参考不影响参数或提示词。异步载图期间切换角色，不会把旧角色图片放进新角色。

中间分隔条支持鼠标 / 触摸拖动及键盘：聚焦后按上下键每次调整 2%，Shift 加速，Home / End 到达当前可用高度边界。布局始终为提示词保留最小空间。主题、导航折叠和分隔比例可在浏览器允许时记住。

## v0.10 行为保持

固定只阻止随机修改，仍可手动改值；混合分组固定、数值范围、文字候选、相关组整体跳过、原文身份描述、关闭 / 缺省 / 中性区别、身体随机显式加入、重抽撤销、导入 / 导出及编译警告保持原逻辑。详情见 `WORKBENCH-v0.10.zh-CN.md`。

## 验证边界

- Node 单元与整合测试覆盖工作区不可变快照、边界校验、原文兼容和原有编译 / 采样
- 最小 DOM 事件脚本分别运行源码与离线包，覆盖两套主题、标签、折叠、拖动事件、键盘、角色 / 版本、导入竞争、参考图状态与失败路径
- 这些脚本模拟 DOM，不是浏览器；尚未验证实际像素、各尺寸滚动、真实焦点、原生文件对话框、剪贴板和本地存储行为
- 没有部署、推送 GitHub、创建 PR 或连接图像生成服务
