# Visage v0.12：人物选项、分区重抽与中英文局部提示词

## 直接使用

打开离线文件 `dist/visage-workbench.html`。不需要安装依赖、登录、联网或图像 API。保留原来喜欢的卡片式浅色／深色界面、角色与版本列表、静态参考图，以及可拖动和键盘调整的中间分隔条。

这次完成的是参数和提示词工具。界面中的图片仍是静态参考，不会根据参数、输出范围或语言变化；没有新增图像生成、3D 或实时换装后端。

## 1. 人物设定：常用选项 + 任意手写

“头部 → 人物设定”中，外貌／族裔描述、性别呈现、肤色、脸型都可以从常用选项选择，也能直接编辑下方文字。选择“自定义／更多描述”会聚焦输入框，不会清空已有内容。选择“未指定”才会清空该可选字段。

- 外貌／族裔选项是宽泛的创作文字快捷项，不是完整的人群分类，也不是对真实人物族裔的判断
- 不依据族裔、性别或肤色推导五官、骨架或身体数值
- 没有强制指定族裔或肤色；新角色的性别呈现仍默认“不强调性别”
- 预设选择和手动编辑一样，不会自动解锁、增加随机候选或改动其他字段
- 导入的任意文字、空格、下划线和固定状态仍按配置原样保存；不认识的文字自动显示为自定义
- 文字候选池仍是单独的可选功能，只有明确加入候选并解除固定，才会在对应重抽中选取

“固定”只阻止随机更改，仍可以手动编辑。固定不存在的字段，会保留它的不存在状态，不会替你补一个默认值。

## 2. 复制反馈会自动关闭

复制成功后提示约 2.5 秒自动消失。连续点复制会重新计时，旧计时器不会提前关掉新提示。

只有浏览器 Clipboard API 成功，或备用复制命令明确返回成功，才显示“已复制”。两条路径都失败时，会选中提示词并诚实提示按 Ctrl+C／⌘C；错误提示约 8 秒后关闭。延迟完成的旧复制不会覆盖后来的角色／输出编辑消息。提示有辅助技术的状态播报标记。

## 3. 全局重抽和当前标签重抽

顶部“全局重抽未固定项”：覆盖头部、外观和已经启用的身体参数，不受当前标签限制。

底部“只重抽头部／外观／身体”：跟随当前标签，仅改变该标签的参数。

- 头部：头部形态数值，以及明确配置候选池的人物文字
- 外观：发型、妆容、表情和已启用外观年龄；预设模块只在明确的候选池中重抽，继承的旧外观字段仍可采用所选风格方向
- 身体：仅已启用身体模块内已勾选的轴；不会开启身体、勾选新轴或改变构图
- 明确关闭的外观模块保持关闭；如果你把“关闭／继承／某预设”主动加入候选池，则该候选池就是你允许的变化范围
- 外观年龄必须已经启用并设定数值范围才参与重抽；不会凭空开启年龄
- 全局与本标签按钮都尊重精确固定、数值边界和候选池；关联组任一字段固定或停用，整组跳过
- 本标签只检查它自己范围内的值／候选冲突；其他标签的冲突不会阻止本页操作。全局遇到任一参与域冲突则整次取消
- 只有发生实际变化才换角色种子；全固定或无可变化项是无副作用操作
- 整次重抽是一个撤销事务。改输出语言／范围不取消这个撤销；撤销时保留你最新的输出设置

新界面不再保留容易混淆的“同时重抽身体”开关。历史 JSON 的 `constraints.includeBody` 字段仍保留；没有指定作用域的旧程序调用继续遵守该字段，新的全局／身体页按钮则按上面的明确作用域执行。新采样记录保存 `scope`，便于区分这两种契约。

## 4. EN / 中文是真的切换提示词内容

点输出区的 EN／中文按钮，即可切换编译语言，不会改变人物、固定、角色随机种子或其采样记录状态。

中文覆盖项目拥有的提示模板、形态轴分档、17 个身体轴、发型与妆容目录的几何／材质／配饰词句、表情和年龄模板。翻译在离线文件内确定性完成，没有在线翻译请求。

任意自定义输入和预设覆盖文字不会擅自翻译，可能仍是英文或混合语言。人物常用选项本身存为可编辑文字，也按作者文字处理。旧配置中的自由文本（包括旧采样器已经写入的造型词）同样原样保留，不根据相同字符串猜测它是不是你自己写的。界面明确提示这个边界，不把混合原文声称为全自动翻译。

为避免破坏历史结果，“完整角色 + 英文”保持原编译器逐字节兼容；它沿用原来的空白与下划线整理规则。中文和局部输出保留自定义字段原文。所有模式下，配置中的原始文字始终不会被输出格式改写。

## 5. 输出范围独立于参数检查器

输出提示词标题旁的范围菜单提供：

- 完整角色：所有已启用、可输出的模块，保持原来的构图规则
- 仅面部：面部结构与肤色；不顺带输出人物身份、发型、妆容或身体
- 仅发型：只输出发型内容；不会偷带族裔、性别、年龄、肤色、脸型或“优先面部结构”结尾
- 仅身体：只输出已经开启且符合全身构图条件的身体内容
- 自选模块组合：身份、脸部、发型、妆容、表情、外观年龄、体型可组合

最后一个模块也可以取消勾选，得到明确的空输出与提示；不会偷偷退回完整角色。选中一个关闭或没有内容的模块，也不会自动给它补参数。身体关闭或仍为头肩构图时，“仅身体”不会开启身体或改变构图，请先在检查器中明确修改。

模块选择只筛选输出，不改变参数、模块启用、固定、候选池或角色种子。每个角色的输出设置随 JSON、角色草稿和版本保存。v0.9／v0.10／v0.11 旧配置缺少输出设置时，按完整英文方式打开。

## 6. 未选部分的展示上下文

范围菜单里“补充未选项”是可选层。默认“不补充”，严格只描述选中内容。

- 中性默认展示：为未选部分提供简洁的通用提示，不引用角色保存的未选参数
- 随机展示上下文：从少量内置、温和的展示建议中确定性选择。使用独立“上下文种子”，只在点“换一个展示上下文”时更换；切标签、重新编译、复制、切语言和保存读取都不会重新抽
- 默认／随机补全跳过含有固定字段的未选模块，并显示跳过说明；随机补全不绕过精确锁
- 白模展示：把未选部分作为无涂装的通用白色黏土展示载体。例如仅发型时可在白模头上展示，已选发型的形状、发色和质感仍保留；不会把整个人物或已选头发强行变白，也不会拷贝未选的真实肤色／身份／面部几何

白模是显式的输出呈现要求，不是参数重抽；没有改掉底层人物或固定。所有上下文都只是给图像模型的文字要求，不保证像素级执行或图像身份。完整角色已覆盖所有模块时，不应用未选部分补全。

## 7. 分类扩展计划

本轮不大改三个标签，以免打断既有工作流。后续建议逐步演进为“人物、形体、造型、动作、画面”，让每个未来模块都有一致的颜色、材质、光泽、样式、固定、随机与输出描述契约。

服装、配饰、机器人、机甲、怪物还没有实现。当前仍只支持成年人物。更完整的扩展边界和分期方案见 `PARAMETER-ARCHITECTURE.zh-CN.md`，它是规划，不是当前功能承诺。
